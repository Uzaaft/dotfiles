# Apple Human Interface Guidelines Overview

Source: https://developer.apple.com/design/human-interface-guidelines

## Purpose

The Human Interface Guidelines help you design apps and games that feel native on Apple platforms while preserving product identity.

## Core principles

1. Hierarchy: Build a clear visual hierarchy where content is primary and controls are legible and discoverable.
2. Harmony: Align UI shape language with the concentric hardware and system design language.
3. Consistency: Follow platform conventions so your app adapts predictably across window sizes, displays, and input modes.

## Design foundations to review first

1. App icons
2. Color
3. Materials
4. Layout
5. Icons
6. Accessibility

## Practical baseline for implementation

1. Prefer system components before custom controls.
2. Preserve a clear separation between content and navigation layers.
3. Make accessibility settings first-class constraints, not post-processing fixes.
4. Verify behavior across orientation, display sizes, Dynamic Type, and contrast settings.
