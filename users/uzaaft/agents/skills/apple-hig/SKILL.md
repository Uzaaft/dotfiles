# Apple Human Interface Guidelines

Use this skill when building or reviewing Apple app UI and interaction design for iOS, iPadOS, or macOS.

## Workflow

1. Start with [references/hig-overview.md](references/hig-overview.md) for shared cross-platform principles.
2. Read [references/liquid-glass-adoption.md](references/liquid-glass-adoption.md) for modern material and component behavior updates.
3. Use [references/liquid-glass-materials.md](references/liquid-glass-materials.md) to select `regular` versus `clear` Liquid Glass and content-layer materials.
4. Use [references/liquid-glass-custom-views.md](references/liquid-glass-custom-views.md) before implementing custom effects in SwiftUI.
5. Open the relevant platform guide before proposing UI structure, navigation, and interaction patterns.
6. Validate recommendations against accessibility, platform conventions, and standard framework components.
