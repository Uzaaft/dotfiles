# Uzaaft Skills

Personal coding-agent skills.

This repository follows the layout used by `dmmulroy/skills`: each skill is a top-level directory with its own `SKILL.md` and any supporting references or scripts beside it.

## Skills

- `commit-messages/` — write clear version-control commit messages.
- `neki/` — PlanetScale Neki and Postgres sharding guidance.
- `postgres/` — PostgreSQL and PlanetScale Postgres guidance.
- `tmux/` — use tmux for long-running background processes.
- `ui/` — UI exploration and refinement guidance.

## Principles

- Keep each skill focused and discoverable.
- Keep shared reference material next to the skill that uses it.
- Prefer small, explicit instructions over broad generic guidance.
